AutoCare 🚗

AutoCare je Android aplikacija za praćenje održavanja vozila, troškova i servisnih zapisa.
Cilj aplikacije je omogućiti korisnicima jednostavno upravljanje svim važnim informacijama vezanim uz njihova vozila na jednom mjestu.

Funkcionalnosti
Dodavanje i upravljanje više vozila
Evidencija servisa i troškova
Praćenje potrošnje goriva
Podsjetnici za registraciju i servise
Pregled statistike i ukupnih troškova
Sigurna pohrana podataka po korisniku
Tehnologije
Kotlin
Android Studio
Jetpack Compose
MVVM arhitektura
Room Database
Firebase Firestore
Kotlin Coroutines
Arhitektura

Aplikacija koristi MVVM (Model-View-ViewModel) arhitekturu radi bolje organizacije koda, lakšeg održavanja i skalabilnosti projekta.
